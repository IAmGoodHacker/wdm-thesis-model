# Розрахункова модель адаптивного термінала WDM

Програма до магістерської дисертації
**“Адаптивні можливості архітектури терміналів транспортних систем електронних комунікацій за технологією спектрального ущільнення”**
(Процюк В. А., науковий керівник – доцент Бердников О. М., ІСЗЗІ КПІ ім. Ігоря Сікорського, 2026).

Програма відтворює всі розрахунки розділів 2 і 3 дисертації:

* GSNR маршрутів за GN-моделлю, оптимальну потужність на канал;
* вибір режиму термінала для чотирьох архітектур (А – фіксована 100G, Б – фіксована 400G, В – адаптивна з дискретними форматами, Г – адаптивна з імовірнісним формуванням сузір’я);
* ємність волокна, кількість транспондерів, потребу в регенерації, час до вичерпання ємності;
* довжину ділянки за енергетичним бюджетом, хроматичною та поляризаційною модовою дисперсією;
* способи збільшення довжини ділянки підсилення.

Результатом роботи програми є таблиці 2.2–2.5, 3.2–3.11 і рисунки 2.1–2.4, 3.1–3.7 дисертації.

## 1. Що потрібно

| Що | Версія |
|---|---|
| Операційна система | Windows 10/11, Linux або macOS |
| Python | 3.9 або новіший |
| Бібліотеки | NumPy, SciPy, Matplotlib (встановлюються однією командою, див. п. 6) |
| Інтернет | лише для завантаження програми та встановлення бібліотек |

Програма працює без графічного інтерфейсу: її запускають з командного рядка, а результати виводяться у вікно командного рядка та зберігаються як зображення.

## 2. Встановлення Python

Спочатку перевірте, чи Python уже встановлено. Відкрийте командний рядок (клавіші **Win + R**, введіть `cmd`, натисніть **Enter**) і виконайте:

```
python --version
```

Якщо з’явилося `Python 3.9` або новіша версія, переходьте до п. 3.

Якщо з’явилося повідомлення про помилку або відкрився Microsoft Store:

1. Відкрийте сторінку https://www.python.org/downloads/ і натисніть **Download Python 3.x.x**.
2. Запустіть завантажений файл.
3. **Обов’язково** поставте позначку **“Add python.exe to PATH”** у нижній частині першого вікна інсталятора.
4. Натисніть **Install Now** і дочекайтеся завершення.
5. Закрийте командний рядок, відкрийте його знову і повторно виконайте `python --version`.

> На Windows замість `python` можна також використовувати команду `py`, наприклад `py --version`.

## 3. Завантаження програми з GitHub

Відкрийте сторінку репозиторію:

**https://github.com/IAmGoodHacker/wdm-thesis-model**

Є два способи завантажити програму.

**Спосіб 1 – завантажити архів (простіше).**

1. Натисніть зелену кнопку **Code**.
2. У меню, що відкрилося, натисніть **Download ZIP**.
3. Архів `wdm-thesis-model-main.zip` збережеться в папку **Завантаження** (Downloads).

> Якщо у репозиторії лежить файл `wdm-thesis-model.zip`, можна завантажити лише його: натисніть на назву файлу, а потім кнопку **Download raw file** (значок стрілки вниз праворуч).

**Спосіб 2 – через Git (якщо Git встановлено).**

```
git clone https://github.com/IAmGoodHacker/wdm-thesis-model.git
```

У цьому випадку архів розпаковувати не потрібно – переходьте до п. 5.

## 4. Розпакування архіву

**Windows:**

1. Відкрийте папку **Завантаження**.
2. Натисніть **правою кнопкою миші** на архів (`wdm-thesis-model-main.zip` або `wdm-thesis-model.zip`).
3. Виберіть **Видобути все…** (Extract All…).
4. У вікні, що відкрилося, вкажіть папку, куди розпакувати, наприклад `C:\wdm-thesis-model`, і натисніть **Видобути**.

> Не запускайте файли безпосередньо з архіву, подвійним клацанням відкривши ZIP у Провіднику. Python не зможе знайти модулі програми, якщо вона не розпакована.

> Уникайте кириличних символів і пробілів у шляху до папки (наприклад, `C:\Users\Віталій\Мої документи\...`). Якщо виникають помилки, розпакуйте архів у `C:\wdm-thesis-model`.

**Linux / macOS:**

```
cd ~/Downloads
unzip wdm-thesis-model-main.zip
```

**Перевірка.** Після розпакування відкрийте папку і переконайтеся, що в ній **безпосередньо** лежать:

```
main.py
README.md
requirements.txt
wdm_model\        (папка)
figures\          (папка, може бути відсутня – вона створюється програмою)
```

Якщо після розпакування ви бачите ще одну папку з тією самою назвою (наприклад, `C:\wdm-thesis-model\wdm-thesis-model-main\`), то файли лежать усередині неї – саме її і треба використовувати далі.

## 5. Відкриття командного рядка в папці програми

**Windows (найпростіше):**

1. Відкрийте розпаковану папку з файлом `main.py` у Провіднику.
2. Клацніть на адресний рядок угорі вікна (де показано шлях до папки).
3. Видаліть шлях, введіть `cmd` і натисніть **Enter**.

Відкриється командний рядок, який уже перебуває в потрібній папці.

**Інший спосіб** – перейти в папку командою `cd`:

```
cd C:\wdm-thesis-model
```

Перевірте, що ви в правильній папці:

```
dir
```

(у Linux/macOS – `ls`). У списку має бути файл `main.py`.

## 6. Встановлення бібліотек

Виконайте одну команду (лише перший раз):

```
python -m pip install -r requirements.txt
```

Будуть встановлені NumPy, SciPy та Matplotlib. Встановлення займає 1–3 хвилини.

> **Необов’язково, але рекомендовано:** щоб бібліотеки не змішувалися з іншими проєктами, можна спочатку створити віртуальне середовище:
>
> ```
> python -m venv venv
> venv\Scripts\activate
> python -m pip install -r requirements.txt
> ```
>
> У Linux/macOS друга команда – `source venv/bin/activate`. Після активації на початку рядка з’явиться `(venv)`. Під час кожного наступного запуску програми спочатку виконуйте команду активації.

## 7. Запуск програми

**Лише таблиці** (вивід у вікно командного рядка):

```
python main.py
```

**Таблиці та рисунки:**

```
python main.py --figures
```

Рисунки буде збережено в папку `figures` усередині папки програми (11 файлів PNG з роздільною здатністю 200 dpi). Розрахунок займає кілька секунд.

**Зберегти результати у текстовий файл:**

```
python main.py > results.txt
```

Файл `results.txt` з’явиться в папці програми. Якщо в Блокноті замість кирилиці відображаються незрозумілі символи, виконайте перед запуском команду `chcp 65001` або відкрийте файл у Notepad++ / VS Code.

## 9. Як змінити вихідні дані

Відкрийте потрібний файл у будь-якому текстовому редакторі (Блокнот, Notepad++, VS Code), змініть значення, збережіть файл і знову запустіть `python main.py`.

**Параметри лінії** – клас `LineParams` у файлі `wdm_model/gn_model.py`:

```python
alpha_db: float = 0.22        # коефіцієнт загасання, дБ/км
disp: float = 17.0            # коефіцієнт хроматичної дисперсії, пс/(нм·км)
gamma: float = 1.3            # коефіцієнт нелінійності, 1/(Вт·км)
span_km: float = 80.0         # довжина підсилювальної ділянки, км
extra_loss_db: float = 3.0    # додаткові втрати ділянки, дБ
nf_db: float = 5.5            # коефіцієнт шуму EDFA, дБ
bwdm_hz: float = 4.8e12       # ширина зайнятого спектра, Гц
snr_trx_db: float = 21.0      # власне ВСШ трансивера, дБ
```

**Маршрути мережі** – список `ROUTES` у файлі `wdm_model/modes.py`. Щоб додати маршрут, допишіть рядок у форматі `('Назва', довжина_в_км)`. Довжину бажано задавати кратною довжині ділянки (80 км).

**Пороги форматів модуляції** – список `FORMATS_64G` у файлі `wdm_model/modes.py`.

**Параметри ділянки для розділу 3** – клас `SpanParams` у файлі `wdm_model/span_budget.py`: рівень передавача, чутливість приймача, втрати на з’єднаннях, будівельна довжина кабелю, експлуатаційний запас.

> Зберігайте десяткову **крапку** (`0.22`), а не кому, та не видаляйте символ `#` перед коментарями.

## 10. Структура програми

```
wdm-thesis-model/
├── main.py               – головний файл: запуск розрахунків і виведення таблиць
├── requirements.txt      – список бібліотек
├── README.md             – ця інструкція
├── figures/              – рисунки (створюються командою python main.py --figures)
└── wdm_model/
    ├── __init__.py
    ├── gn_model.py       – GN-модель: шум ASE, нелінійні завади, GSNR, P_opt   – формули (2.1)–(2.6)
    ├── modes.py          – маршрути, вибір формату, швидкість PCS, транспондери – формули (1.11), (2.7)
    ├── span_budget.py    – енергетичний бюджет, дисперсія, статистика DGD       – формули (3.1)–(3.9)
    └── plots.py          – побудова рисунків і сценарії підрозділу 3.6
```

## 11. Можливі помилки та їх усунення

| Повідомлення | Причина | Що зробити |
|---|---|---|
| `'python' is not recognized as an internal or external command` | Python не встановлено або не додано до PATH | Перевстановіть Python з позначкою **Add python.exe to PATH** (п. 2) або використовуйте команду `py` замість `python` |
| `can't open file '...main.py': No such file or directory` | командний рядок відкрито не в папці програми | Перейдіть у папку, де лежить `main.py` (п. 5), перевірте командою `dir` |
| `ModuleNotFoundError: No module named 'numpy'` (або `scipy`, `matplotlib`) | не встановлено бібліотеки | Виконайте `python -m pip install -r requirements.txt` (п. 6); якщо використовуєте віртуальне середовище – спочатку активуйте його |
| `ModuleNotFoundError: No module named 'wdm_model'` | програму запущено з архіву або з іншої папки | Розпакуйте архів (п. 4) і запускайте з папки, де одночасно лежать `main.py` і папка `wdm_model` |
| `'pip' is not recognized...` | pip не в PATH | Використовуйте `python -m pip ...` замість `pip ...` |
| Замість кириличних символів – «кракозябри» | кодування консолі Windows | Виконайте `chcp 65001` перед запуском або запускайте з Windows Terminal / VS Code |
| `PermissionError` під час збереження рисунків | папка лише для читання або відкрита в іншій програмі | Розпакуйте програму в папку користувача, наприклад `C:\wdm-thesis-model`, закрийте відкриті рисунки |

**Примітка.** Порогові значення GSNR у табл. 2.2 програма обчислює без проміжних округлень, тому окремі значення можуть відрізнятися від наведених у дисертації на 0,1 дБ. Усі інші результати збігаються з таблицями дисертації.
